# Base de datos MercaKing (MySQL / phpMyAdmin)

## Cómo importar
1. Abre phpMyAdmin (http://localhost/phpmyadmin).
2. Crea una base de datos llamada `mercaking` con cotejamiento `utf8mb4_unicode_ci`.
3. Selecciona la BD `mercaking`.
4. Pestaña **Importar** → selecciona `schema.sql` → Ejecutar.
5. Luego importa `seed.sql` (datos demo).
